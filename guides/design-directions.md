# ทิศทางการออกแบบ (Design directions)

เพื่อไม่ให้ทุกเว็บหน้าตาเหมือนกัน KODRA มีชุด "ทิศทางการออกแบบ" 12 แบบ แต่ละแบบกำหนด
ฟอนต์ สี รูปทรง เลย์เอาต์ และจุดเด่นของหน้าเว็บไว้ครบ

## เลือกอย่างไร

1. เปิด **Settings → Workflow → App Blueprint** (พิมพ์เขียวแอป)
2. เมื่อสร้างแอปใหม่ AI จะเสนอการ์ด **Design direction** มา 3 แบบที่ต่างกัน แต่ละแบบแสดง
   Typography, Shape & depth, Layout concept และ Signature moments
3. กด **Use this direction** ที่แบบที่ชอบ หรือดูแบบอื่นใน **Other directions**

ภายหลังอยากเปลี่ยน ก็พิมพ์สั่งในแชตได้ เช่น *"ออกแบบใหม่เป็นสไตล์ Thai Modern"*

## ทั้ง 12 แบบ

| Direction | ชื่อไทย |
|---|---|
| Editorial | นิตยสาร |
| Swiss Grid | กริดสวิส |
| Luxury Minimal | หรูหรามินิมอล |
| Playful Illustrated | สนุกสดใส |
| Bold Brutalist | ดิบเท่โฉ่งฉ่าง |
| Tech Dark | เทคโทนมืด |
| Organic Craft | ธรรมชาติงานคราฟต์ |
| Retro Vintage | เรโทรวินเทจ |
| Soft Pastel | พาสเทลนุ่มนวล |
| Data-Dense Pro | แดชบอร์ดมืออาชีพ |
| Corporate Trust | องค์กรน่าเชื่อถือ |
| Thai Modern | ไทยร่วมสมัย |

---

## English

KODRA ships 12 design directions (archetypes), each a complete art direction
(type, color, shape, layout, signature moments) so apps don't all look alike.
With **Settings → Workflow → App Blueprint** on, a new app's blueprint shows a
**Design direction** card with 3 contrasting options; pick one with **Use this
direction** (or browse **Other directions**). You can ask for a redesign in any
direction later in the chat. Directions: Editorial, Swiss Grid, Luxury Minimal,
Playful Illustrated, Bold Brutalist, Tech Dark, Organic Craft, Retro Vintage, Soft
Pastel, Data-Dense Pro, Corporate Trust, Thai Modern.
